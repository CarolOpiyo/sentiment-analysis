# Sentiment Analysis

This repository contains my NLP sentiment analysis classwork on cyberbullying detection using tweet data.

## Project Overview

The project uses natural language processing techniques to analyze tweets and classify cyberbullying-related text. The notebook includes data loading, text preprocessing, exploratory analysis, model training, and evaluation.

## Files

- `Cyberbullying_Sentiment_Analysis.ipynb` - Jupyter notebook with the sentiment analysis workflow.
- `cyberbullying_tweets.csv` - dataset used by the notebook.

## How to View the Work

Open `Cyberbullying_Sentiment_Analysis.ipynb` on GitHub to view the notebook code, explanations, and saved results.
